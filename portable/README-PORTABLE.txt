IRIS 快捷查询——免安装版使用说明

1. 请先把 ZIP 完整解压到一个普通文件夹，不要直接在压缩包内运行。
2. 双击 IrisQuickQuery.exe 即可启动，无需安装 .NET，也不会创建卸载项。
3. 软件配置、加密密码、日志和备份仍保存在：
   %LocalAppData%\IrisQuickQuery
   它们不会写入绿色版程序文件夹，也不会被本压缩包携带。
4. 同一台电脑、同一 Windows 用户下，安装版和免安装版会读取同一份已有配置。
5. 复制到其他电脑或其他 Windows 用户后，需要重新配置连接并重新输入数据库密码。
6. 目标电脑必须由医院 IT 预先安装官方 64 位 InterSystems IRIS ODBC35 驱动。
7. 更新绿色版时，请先退出软件，再替换整个程序文件夹；不要删除
   %LocalAppData%\IrisQuickQuery，否则会丢失用户配置。

# Iris 临床数据工作台设计规范

状态：v1 · 2026-08-15  
适用范围：Windows WPF 桌面端  
代表页面：`QueryPage`

## 1. 设计方向与来源

Iris 采用“IBM 式临床数据工作台”方向：通过高对比中性色、单一操作蓝、严格网格和清晰水平分区组织复杂信息。权威感来自结构和可预测性，不来自装饰、阴影或大面积品牌色。

主参考是 OpenDesign 中从 IBM 实际页面计算样式提取的设计系统：

- OpenDesign 详情：<https://opendesign.cc/en/sites/ibm>
- 结构化令牌：<https://opendesign.cc/packs/ibm/spec.json>
- 完整迁移规范：<https://opendesign.cc/packs/ibm/DESIGN_SPEC.zh-CN.md>

医疗工作流所需的状态色使用 IBM Carbon 官方支持色令牌，而不是自定义近似色：

- Carbon 颜色令牌：<https://carbondesignsystem.com/elements/color/tokens/>
- Carbon 通知用法：<https://carbondesignsystem.com/components/notification/usage/>

## 2. 设计原则

1. **结构先于容器**：优先用网格、对齐和分隔线表达层级；只有真正独立的对象才使用面板。
2. **颜色必须有任务**：蓝色只表示操作、焦点和流程进度；支持色只表示明确状态。
3. **患者数据优先**：字段值、来源、冲突和待选择状态始终高于说明文字与品牌信息。
4. **一步一个主操作**：同一区域只允许一个实心主按钮，其他操作降为次级或文字操作。
5. **不依赖颜色单独传意**：状态必须同时具有文本标签；错误、冲突和等待不能只靠色块区分。
6. **核心内容优先**：查询页标题后直接进入查询条件，运行状态由字段状态、结果区和规则运行轨迹共同表达，不额外占用顶部空间。

## 3. 颜色令牌

### 3.1 OpenDesign / IBM 基础令牌

| WPF 令牌 | 值 | 角色 |
|---|---:|---|
| `ColorBackground` | `#FFFFFF` | 应用主背景 |
| `ColorSurfaceMuted` | `#F4F4F4` | 导航、字段和次级层 |
| `ColorNavigationSelected` | `#D0E2FF` | 当前工作区的浅蓝选择面 |
| `ColorText` | `#161616` | 标题、正文、关键数据 |
| `ColorTextSoft` | `#333333` | 次级正文 |
| `ColorTextMuted` | `#525252` | 标签、元数据、帮助文本 |
| `ColorPrimary` | `#0F62FE` | 主操作、焦点、当前步骤 |
| `ColorBorderSubtle` | `#E0E0E0` | 白色背景上的细分隔线 |
| `ColorBorder` | `#C6C6C6` | 层级边界 |
| `ColorBorderStrong` | `#8D8D8D` | 输入框底边和强边界 |

`#0F62FE` 是唯一品牌操作色。不得增加第二个装饰性主色，也不得用渐变制造“科技感”。

### 3.2 Carbon 产品语义扩展

| WPF 令牌 | 值 | 允许用法 |
|---|---:|---|
| `ColorSuccess` | `#24A148` | 查询完成、SQL 回填、连接成功 |
| `ColorWarning` | `#F1C21B` | 等待选择、需要注意但未失败 |
| `ColorDanger` | `#DA1E28` | 值冲突、格式错误、执行失败 |
| `ColorInfo` | `#0043CE` | 非阻断信息与流程进度 |

支持色不得用于普通按钮或装饰。浅色背景上的黄色必须搭配 `#161616` 文本和明确状态词。

## 4. 排版

- 中文 UI：`Microsoft YaHei UI`，确保 Windows 10/11 字形稳定。
- 拉丁字符与数字：允许由系统字体回退；SQL 和日志使用 `Cascadia Mono, Consolas`。
- 页面标题：32px / Regular 400。
- 分区标题：18px / Regular 400。
- 正文：14px；快捷查询输入值固定为 16px，以保证长编号的可读性。
- 标签与元数据：12px；不得低于 12px。
- 只在必须标记结构时使用 `SemiBold`；禁止用连续粗体制造层级。

标题与正文通过尺寸、位置和留白区分，不通过超粗字重区分。

## 5. 间距与布局

基础单位为 4px；可用间距仅限：`4 / 8 / 16 / 24 / 32 / 48 / 64 / 96`。

- 页面左右边距：32px；最小窗口可保持 24px。
- 主分区间距：24px。
- 组件内部间距：16px。
- 同组标签与内容：4px 或 8px。
- 工作区使用 12 列概念网格，标准列沟为 24px。
- 主窗口适配 `1380×860`；最低适配 `1100×680`。

禁止为了填满窗口而拉伸字段。查询字段按其定义宽度排列，剩余空间作为工作区留白；结果表格才使用全宽。

## 6. 表面与边界

- 默认面板为直角或 4px 小圆角；代表页默认使用直角。
- 使用 1px 分隔线建立层级，不给每个区域增加阴影。
- 输入框使用浅灰层和强底边；焦点使用 2px `ColorPrimary` 边界。
- 标签不是胶囊装饰。状态文本与左侧状态轨道共同工作。
- 禁止玻璃拟态、渐变背景、大面积投影和“所有内容卡片化”。

## 7. 组件规则

### 应用导航

- 浅灰导航层，右侧 1px 分隔线。
- 当前页面使用 4px 蓝色指示轨道、浅蓝选择面和明确文字状态。
- 图标使用稳定的文本缩写或矢量图形；不使用依赖字体渲染的装饰符号。

### 命令栏

- 页面标题、说明和主操作处于同一首屏区域。
- 主操作为蓝底白字；次级操作为浅灰底深色字。
- 快捷键作为独立的小型元数据，不嵌入按钮文案制造噪音。

### 查询页状态呈现

- 不设置顶部“查询链路”轨道，标题后直接展示查询条件。
- 人工输入、SQL 回填、冲突和错误由字段本身的状态轨道与输入框样式表达。
- 规则执行细节统一放在页面底部的“规则运行轨迹”，不在首屏重复展示流程说明。

### 元素字段

- 每个字段是数据对象面板，而不是营销卡片。
- 固定信息顺序：中文名称（上）→ 全局元素 key（下）→ 值 → 来源；查询条件卡片不显示分组名和“可输入/不可输入”文字，来源只显示查询对象名称。
- 左侧 4px 状态轨道表示运行状态；能否人工输入由正常输入框或灰色只读样式表达。
- 灰色只读值仍是可选择文本，允许鼠标框选及 `Ctrl+C` 复制；只读不等于不可交互。
- 查询条件卡片纵向保持紧凑，仅在标题、值和来源之间保留必要间距。
- SQL 回填字段保持可复制、双击/F2 编辑的现有交互。
- 查询条件默认显示已选元素；单一“编辑”状态同时展示全部未显示元素和当前元素的移除操作。元素能否人工输入只控制字段输入框，不控制其是否可作为结果字段展示。

### 结果表格

- 表格占据内容全宽；表头位于浅灰层。
- 行高至少 40px，选中行必须具有蓝色焦点提示。
- 选择要求放在表格标题区，不用浮动提示覆盖数据。

### 通知与错误

- 使用左侧 4px 支持色边线、浅灰背景和短句。
- 文案先说状态，再说明下一步，例如：“未执行规则。请先启用至少一条已测试规则。”
- 不使用感叹号、模糊提示或只写“操作失败”。

## 8. 交互与动效

- 微交互：150ms；小型状态变化：240ms；中型过渡上限：300ms。
- WPF 中优先使用即时颜色、边线和透明度反馈，不添加弹跳或位移动画。
- 所有键盘可操作控件必须显示可见焦点。
- Enter 运行、Esc 取消编辑、F2 编辑派生字段、Ctrl+C 复制的现有语义保持不变。

## 9. 文案语气

语气应专业、直接、可执行。标题使用名词或明确动作；按钮使用动词；状态信息说明当前状态和下一步。

推荐：

- “开始查询”
- “等待选择一条记录”
- “值冲突：下游规则已阻断”

避免：

- “立即体验”
- “智能为你查询”
- “出错啦！”

## 10. 禁用清单

- 不用青绿渐变或紫蓝光晕表达技术感。
- 不把每个分区都做成 10–16px 圆角卡片。
- 不使用 10px/11px 正文或浅灰低对比文字。
- 不使用 Emoji 或不稳定的 Unicode 字符充当正式图标。
- 不在一个页面同时出现多个实心主按钮。
- 不用阴影代替清晰的边界和对齐。
- 不为了“更现代”移除数据密度、快捷键或诊断信息。

## 11. 代表页验收标准

- 视线顺序稳定为：页面目的 → 查询条件与主操作 → 输入字段 → 结果/规则轨迹。
- 页面标题与正文尺寸对比至少 2.25；标题保持 Regular。
- 除状态支持色外，只出现一个操作蓝。
- 无圆角卡片堆栈，无装饰性阴影。
- 数据表格按真实列宽收束：元素配置表在最后一个可见配置列结束，查询结果表在最后一个结果列结束，不用空白表格区域填满容器。
- `1380×860` 下不出现不必要的横向滚动。
- `1100×680` 下主操作和至少一行字段保持可见。
- 键盘焦点、状态文字和患者值在浅色主题下清晰可辨。
